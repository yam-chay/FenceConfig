# Fence Configurator — Web Spike

תחילת הפרויקט: קונפיגורטור וירטואלי לגדרות/פרגולות/שערי אלומיניום מותאמים אישית.
הריפו הזה הוא **ספייק בלבד** — המטרה שלו היא לבדוק אמפירית ביצועי WebGL על מובייל
לפני שסוגרים סופית בין web stack ל-Unity (ראה `SPIKE-NOTES.md`).

## הרצה מקומית

```bash
npm install
npm run dev
```

## מה יש כאן

- `src/geometry/` — מתמטיקה טהורה, בלי תלות ב-Three.js:
  - `constants.ts` — קבועי ייצור נעולים (מאושרים מקבצי האקסל של הלקוח) + placeholders למידות שעוד לא אושרו
  - `field.ts` — חישוב ערימת לוחות/מרווחים לשדה בודד לפי גובה מבוקש
  - `post.ts` — spec גיאומטרי לעמוד
  - `run.ts` — פיצול ריצה ישרה לשדות (≤1.5 מ׳ כל אחד) ומיקום עמודים/שדות במרחב, כולל זווית כיפוף לבדיקת שרשור עקום
- `src/scene/Scene.tsx` — הסצנה עצמה: מצלמה קבועה (לא מסתובבת — כמו בספק), תאורה, ובנייה פרוצדורלית מחדש בזמן אמת מכל שינוי פרמטר
- `src/App.tsx` — פאנל בדיקה עם סליידרים (אורך/גובה/זווית) + מד FPS/draw calls/triangles

## מה זה בודק

השאלה המרכזית: **האם גיאומטריה פרוצדורלית בזמן אמת (ללא מודלים שמורים) רצה חלק על מובייל ב-WebGL?**
תריצו על מכשיר סלולרי אמיתי, תמשכו את הסליידרים (בעיקר אורך ריצה — הכי משפיע על מספר המשולשים),
ותסתכלו על ה-FPS badge.

## מה עוד לא כאן (במכוון — זה ספייק, לא המוצר)

- טקסטורות צבע אמיתיות (כרגע צבע שטוח בלבד)
- זום-אין על עמוד/שדה בלחיצה
- קרוסלות סוג/גודל/צבע
- פאנל מדידה עם shape builder רב-צלעי (90° פינות/עמוד כפול)
- מונה חומרים (בורגים, רוזטות וכו׳)
- שיתוף לינק / ייצוא
- כל מסך חוץ מהבנייה עצמה (בית, קטלוג, מדריכים)

ראו את `areas/fence-configurator-client.md` בזיכרון הפרויקט לספק המלא.
